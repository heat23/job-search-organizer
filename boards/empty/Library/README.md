# Library

Put your guides here as Markdown files: `Library/<Group>/<NN>_<Title>.md`, where the folder becomes a group in the
Prep library tab and the number sets the order. The sample board in the project repository (`boards/sample/Library`) has
three guides that show every piece of markup; copy their `.md` files in to start.

`My_answers.md` appears here once you write your own version of an answer. Only the page writes it.
