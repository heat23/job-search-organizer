# Job notes

One folder per job, named by the job's id in `board_data.js`.

| File | Who writes it | What it is |
|---|---|---|
| `prep.md` | you (or a tool you use) | Talking points for a call. Any Markdown with `## sections`. |
| `outreach.md` | you | A note to the hiring manager, screening answers. |
| `posting.md` | you | A saved copy of the job posting. |
| `my_notes.md` | the page only | Your notes pad from the prep sheet. |

`hunters/<id>/my_notes.md` holds your notes for each headhunter.
What you type in a prep sheet's answer boxes ("My version", "Their answer") is saved in `Library/My_answers.md`.
Nothing here moves when a job changes stage, and removing a card never deletes its notes.
If two versions of a notes file collide, both are kept: `my_notes.changed-on-disk-<time>.md` sits beside it.
